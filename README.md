# BA-3.2-AI-Capstone-Project

## Overview
This AI with python based project breaks down the hypertension dataset using machine-learning algorithms.

##Files Included

- **importing_dataset.py** — loads and cleans the dataset  
- **algorithms_machine_learning_txt_website.py** — extracts algorithm details from text sources  
- **machine_learning_algorithms.py** — defines and trains models  
- **suitable_algorithms.py** — selects best models based on performance  
- **train_models.py** — runs training sessions  
- **training.py** — evaluates model accuracy  
- **separating.py** — separates data into training and testing sets  
- **rough_draft_of_hypertension_coding.py** — early prototype code
